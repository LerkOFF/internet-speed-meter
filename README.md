# internet-speed-meter

Скрипт-замерятель скорости интернета со своего компьютера. Получает адрес тяжёлого файла (например, большой картинки), 10 раз подряд скачивает его целиком и печатает:

- среднее время запроса;
- объём скачанных данных;
- скорость в МБ/с, а рядом в Мбит/с, чтобы сравнить с тарифом провайдера.

Скрипт написан на стандартной библиотеке Python, ставить ничего не надо.

## Требования

Python 3.8 или новее (проверено на 3.9 и 3.14):

```bash
python3 --version
```

На Windows команда `py --version`.

## Запуск

```bash
git clone https://github.com/LerkOFF/internet-speed-meter.git
cd internet-speed-meter
python3 speed_meter.py https://images-assets.nasa.gov/image/as11-40-5903/as11-40-5903~orig.jpg
```

На Windows вместо `python3` пишите `py`.

В примере фотография Базза Олдрина на Луне из архива NASA, 3,2 МБ. Подойдёт любая прямая ссылка на файл. Например, тестовый файл Selectel на 10 МБ, он открывается из России без VPN:

```bash
python3 speed_meter.py https://speedtest.selectel.ru/10MB
```

Чем файл больше, тем точнее замер: на маленьком файле заметную долю времени съедает установка соединения. Удобно брать файлы от 3 до 20 МБ.

## Параметры

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `url` | обязательный | адрес файла; если не указать `http://` или `https://`, подставится `https://` |
| `-n`, `--count` | `10` | сколько запросов сделать |
| `-t`, `--timeout` | `30` | сколько секунд ждать ответа сервера, прежде чем считать запрос неудачным |

Например, 5 запросов с таймаутом 10 секунд:

```bash
python3 speed_meter.py -n 5 -t 10 https://speedtest.selectel.ru/10MB
```

## Как считается

1. Запросы идут строго по очереди: следующий начинается, только когда предыдущий скачан до последнего байта.
2. Время запроса считается от отправки до последнего байта ответа. Сюда входят DNS, TCP- и TLS-соединение: каждый запрос открывает новое соединение.
3. Объём: сумма байт в телах всех успешных ответов. Сжатие выключено заголовком `Accept-Encoding: identity`, поэтому считаются байты самого файла. Заголовок `Cache-Control: no-cache` просит промежуточные кэши не подсовывать сохранённую копию.
4. Среднее время запроса: суммарное время, делённое на число успешных запросов.
5. Скорость: объём, делённый на суммарное время. 1 МБ = 1 000 000 байт; в скобках та же скорость в Мбит/с (умножить на 8), в таких единицах пишут тарифы.

Неудачный запрос (HTTP-ошибка, таймаут, обрыв соединения) печатается как ошибка и в расчёт не идёт. Если не удался ни один, скрипт завершается с кодом 1. По Ctrl+C замер останавливается и печатает итог по уже скачанным файлам.

## Тесты

```bash
python3 -m unittest -v
```

Тесты поднимают локальный HTTP-сервер, интернет для них не нужен. Проверяют подсчёт байт, число запросов, HTTP-ошибку, оборванный ответ и разбор параметров.

## Если что-то не так

- `HTTP 429 Too many requests`: сервер ограничивает частые скачивания. Так делает, например, upload.wikimedia.org, причём и с оригиналами, и с превью. Возьмите другой адрес.
- `HTTP 403 Forbidden`: сервер не отдаёт файл скриптам. Скрипт представляется своим User-Agent, но некоторые сайты пускают только браузеры.
- `CERTIFICATE_VERIFY_FAILED` на macOS: у Python, установленного с python.org, нет корневых сертификатов. Запустите `Install Certificates.command` из папки `/Applications/Python 3.x/`.
